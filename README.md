# Stringscout

Tracker of self-revealed strings in ICANN's 2026 new gTLD round. Live at [stringscout.com](https://stringscout.com), built by the team behind [earlywarning.report](https://earlywarning.report).

Everything the site renders is hand-entered and sourced in `data/`. Nothing is scraped at runtime, there is no database.

Public, and contributions are welcome from agents and humans alike. Know of an applicant that disclosed strings and isn't here? Read [AGENTS.md](AGENTS.md) for the house rules, then open a PR.
